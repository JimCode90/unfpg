# 2. Recibir una issue

Una **issue** es una tarea. Te la asigna el líder en GitHub.

## Pasos

1. **Abre la issue** y léela completa (título, descripción y lista de tareas).
2. **Fíjate en el número.** Ejemplo: `#12`. Lo vas a usar en tu rama y en tu Pull Request.
3. **Si algo no queda claro, pregunta** en los comentarios de la issue antes de empezar.
4. **Comenta que la tomas:** escribe `Empiezo a trabajar en esto`.
5. **Pasa a [crear tu rama](03-crear-rama.md).**

## Cómo debe ser una buena issue (guía para el líder)

```
Título: Crear CRUD de Alumno

Descripción:
Qué se necesita y por qué.

Tareas:
- [ ] Crear entidad
- [ ] Crear repositorio
- [ ] Crear servicio
- [ ] Crear controlador

Criterio de terminado:
- El proyecto compila
- Los endpoints responden en Postman
```

## Si te bloqueas

Escribe un comentario en la issue explicando qué intentaste y dónde te quedaste. No te quedes callado.
