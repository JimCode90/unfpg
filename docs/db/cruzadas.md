# Tablas Cruzadas (3)

**Por qué son cruzadas:** resuelven una relación muchos a muchos entre dos tablas. Su llave primaria está formada por las dos claves foráneas (llave compuesta) y casi no tienen datos propios.

| # | Tabla | Por qué |
|---|---|---|
| 1 | docentegrado | relaciona docente con gradoinstruccion (un docente tiene varios grados) |
| 2 | empleadogrado | relaciona empleado con gradoinstruccion (un empleado tiene varios grados) |
| 3 | usuariorol | relaciona usuario con rol (un usuario tiene varios roles) |
